# Getting Started with Triathlon

## What is Triathlon?

Triathlon is a multi-sport endurance event consisting of three sequential disciplines: swimming, cycling, and running, performed in that order. The transition between each sport (T1: swim-to-bike, T2: bike-to-run) is also timed, making smooth transitions part of the race.

## Why Triathlon?

- **Complete fitness:** Develops cardiovascular endurance, muscular strength, and overall athleticism
- **Variety:** Three sports mean you're never doing the same workout every day
- **Community:** Welcoming, supportive community of athletes
- **Personal challenge:** Set and achieve meaningful goals
- **Cross-training benefits:** Reduced injury risk compared to single-sport training

## Choosing Your First Race

### Sprint Distance (Best for Beginners)
- **Distances:** 750m swim / 20km bike / 5km run
- **Typical finish time:** 1:00-2:30
- **Training time needed:** 8-12 weeks
- **Weekly training:** 4-6 hours

**Why start here:** Short enough to be achievable, long enough to experience the full triathlon challenge. Most beginner-friendly distance.

### Olympic Distance
- **Distances:** 1.5km swim / 40km bike / 10km run
- **Typical finish time:** 2:15-4:00
- **Training time needed:** 12-16 weeks
- **Weekly training:** 6-10 hours

**Choose this if:** You have endurance sport background or completed a sprint and want more challenge.

### Selecting a Race

Consider these factors:
1. **Course profile:** Flat vs. hilly bike and run courses
2. **Water type:** Pool swim vs. open water (lake/ocean)
3. **Climate:** Temperature and humidity on race day
4. **Location:** Local race vs. destination event
5. **Timing:** Allow adequate preparation time

## Assessing Your Starting Point

### Swimming Assessment
- Can you swim 100m continuously without stopping?
- Are you comfortable putting your face in water?
- Can you tread water for 2 minutes?

**If no to any:** Start with swim lessons before training plan

### Cycling Assessment
- Do you have access to a functional bike?
- Can you ride 30 minutes comfortably?
- Are you confident handling a bike (turning, braking, gears)?

**If no to any:** Practice basic bike handling before structured training

### Running Assessment
- Can you jog for 10 minutes continuously?
- Do you have appropriate running shoes?
- Any current or recurring injuries?

**If no/injured:** Build walking/running base or see physical therapist

## Common Beginner Mistakes to Avoid

### 1. Doing Too Much, Too Soon
Build volume gradually. Increase weekly volume by no more than 10% each week.

### 2. Neglecting the Weakest Sport
Most beginners ignore swimming. If swimming is your weakness, make it a priority.

### 3. Skipping Brick Workouts
Practice running immediately after cycling. This is a unique triathlon skill.

### 4. Ignoring Transitions
Practice T1 and T2. Many beginners lose significant time in transition.

### 5. Not Training with Race Nutrition
Never try anything new on race day. Test all nutrition during training.

### 6. Overlooking Recovery
Rest is when adaptation happens. Training without recovery = injury/burnout.

### 7. Buying Too Much Gear Early
Start with basics. Upgrade as you commit to the sport.

## Building Your Training Schedule

### Weekly Structure Template

| Day | Sprint Plan | Olympic/70.3 Plan |
|-----|--------------|-------------------|
| Monday | Rest or easy swim | Rest |
| Tuesday | Bike + Run | Swim + Bike |
| Wednesday | Swim | Bike + Run |
| Thursday | Bike | Swim + Run |
| Friday | Run | Swim |
| Saturday | Brick (Bike + Run) | Long Bike |
| Sunday | Rest or active recovery | Long Run |

### Time Management Tips

1. **Morning training:** Get it done before daily obligations
2. **Combine sessions:** Bike to the pool, run home
3. **Lunch workouts:** Use lunch break for short sessions
4. **Weekend long sessions:** Schedule long rides and runs
5. **Communicate:** Share your schedule with family/support system

## The Mental Side of Starting

### Setting Goals
- **Process goals:** Complete all scheduled workouts, improve technique
- **Performance goals:** Finish within target time, negative split the run
- **Outcome goals:** Finish the race, place in age group (secondary)

### Managing Expectations
- First race is about finishing, not time
- Progress is not linear
- Everyone has bad workouts
- Comparison is the thief of joy

### Building Confidence
- Master one skill at a time
- Celebrate small victories
- Keep a training log
- Training partners provide accountability and motivation

## First 30 Days Checklist

### Week 1: Assessment
- [ ] Swim assessment (continuous swim test)
- [ ] Bike fit check at local shop
- [ ] Run gait assessment or shoe fitting
- [ ] Choose and register for race

### Week 2: Base Building
- [ ] Begin 3x/week in each sport
- [ ] Focus on technique over intensity
- [ ] Establish rest/schedule routine
- [ ] Start training log

### Week 3: Routine
- [ ] Add brick workout (bike + run back-to-back)
- [ ] Practice transition setup
- [ ] Test nutrition on longer sessions
- [ ] Evaluate and adjust schedule

### Week 4: Progression
- [ ] Gradually increase session duration
- [ ] Add one intensity session per sport
- [ ] Research race-specific demands
- [ ] Find training partners or group
