# 16-Week Training Plan for Olympic Triathlon

## Olympic Triathlon Distances
- **Swim:** 1.5km (0.93 miles / 1500m)
- **Bike:** 40km (24.8 miles)
- **Run:** 10km (6.2 miles)
- **Total:** Approximately 32 miles

## Plan Overview

This 16-week plan is designed for athletes targeting an Olympic distance triathlon. It assumes you can currently:
- Swim 800m continuously
- Bike for 60 minutes
- Run for 45 minutes

### Training Volume
- **Week 1:** 5-6 hours
- **Peak Week:** 10-11 hours
- **Weekly structure:** 3 swims, 3 bikes, 3 runs, 1 brick

### Terminology

| Term | Definition |
|------|------------|
| **WU** | Warm-up |
| **MS** | Main Set |
| **CD** | Cool-down |
| **RI** | Rest Interval |
| **Low aerobic** | Very comfortable, conversational |
| **Moderate aerobic** | Comfortable but purposeful |
| **Threshold** | "Comfortably hard," ~80-85% max HR |
| **VO2max** | Hard effort, 90-95% max HR |
| **Speed** | Near-maximum effort |
